$ Command reference

bohselecta popup claude
Open the Ratatui chooser in a dedicated tmux session. Add --model opus or --cwd /path/to/project if needed.
bohselecta preview claude
Open the command-only preview on Sonnet. Use an offered /boh:sonnet, /boh:opus, or /boh:haiku command to continue a saved task.
boh: keep · boh: cancel
Inside either Claude preview, continue a saved task on the current model or discard it. boh: off, boh: on, and boh: status control advice.
bohselecta install codex
Install the existing Codex hooks. Use the suggested model picker, then resubmit your task. The Ratatui popup is Claude-only.
bohselecta native status
Check installed hooks, client versions, and catalog freshness. Does not report whether a popup session is open.
bohselecta native refresh claude
Refresh available Claude models without executing a task.
bohselecta history
Review tasks, recommendations, choices, and outcomes. bohselecta history delete ID removes one local record.
bohselecta --help
Explore all commands, including native hook installation and removal.
What happens when I press Enter?+

The popup closes. If you picked another model, a helper waits for Claude’s matching paused task and an empty prompt, then submits its direct model command. The saved task is claimed once and continues in the same conversation.

Choosing the current model or pressing Escape continues the original prompt. q and Ctrl-C cancel; 90 seconds without a choice also cancels.

No popup? It may already be the right model.+

The preview starts on Sonnet. Ordinary work such as build todo app can run immediately because Sonnet is already the first recommendation. That is quiet routing, not a missing hook.

To exercise the chooser, launch bohselecta popup claude --model opus and try todo app. Check bohselecta history in another terminal to see whether a prompt was recorded.

What’s experimental?+

The popup uses terminal automation and currently requires Claude Code 2.1.282. It is tested with tmux 3.7c. It does not add a native model-switch API. Don’t type ahead during the handoff; if readiness isn’t confirmed within 12 seconds, use the displayed continuation command.

The model override lasts one turn. Later prompts are checked again. Haiku is excluded in auto and plan permission modes. The popup does not change your saved default or tool permissions.

Why is there still a hook notice?+

Claude displays “Operation stopped by hook” when bohselecta pauses the original prompt to switch models. The popup removes manual command entry, but that client-owned notice and the submitted command remain visible.

Disabled, missing, or timed-out hooks may let Claude continue on its current model. This is model advice, not a guaranteed spending limit.

How does it choose and learn?+

Local rules classify scope and difficulty, filter for sufficient capability, and prefer the lowest configured cost tier. Uncertainty can produce two options. A suitable current model continues quietly.

Rate finished tasks with boh: feedback good, boh: feedback stronger, boh: feedback cheaper, or boh: feedback unsure. Stronger feedback can raise the capability floor. Successful-choice reuse requires matching model evidence; preview completion hooks do not independently verify the execution model.

Does it know actual prices?+

It uses relative cost tiers, not live prices or measured savings. Tier 2 does not mean twice the price of tier 1. Native routing makes no paid classification call.

Dated pricing, token and cache estimates, and separate subscription/API treatment are planned. Switching providers is also future work.

Where does my data go?+

Task text, context excerpts, outputs, choices, and feedback stay in the local store at ~/.local/share/bohselecta. Files are private to your OS user, not encrypted. Default retention is 90 days. The popup briefly uses a private temporary file with a task excerpt.

Routing is local. When a task continues, Claude sends it through its usual provider and retains its own transcript. Saved continuations expire after 24 hours and are scoped to the same session and folder.

Can I still use normal Claude or Codex?+

Yes. The popup plugin is loaded only for that launch. Exit and open your usual client to return to your existing setup. The command-only Claude preview needs no tmux or Rust.

The v0.2.2 native hooks support both clients with manual model changes and task resubmission. Only the Claude popup submits the chosen continuation command for you.

WORKING PREVIEWUnreleased / Claude only

Choose. Enter. Back to work.

  • Ratatui popup over Claude’s terminal, hosted in a dedicated tmux session.
  • Enter chooses and continues; Escape keeps the current model; q cancels.
  • Sonnet by default, quiet routing for suitable tasks, and short commands as a fallback.
  • Continuation tied to the exact saved task, with checks for the correct pane and an empty prompt.

Live tests verified Sonnet execution, keeping Opus, and cancellation. 67 JavaScript/TypeScript tests and 2 Rust tests pass. Tested on Claude Code 2.1.282 and tmux 3.7c; hook notices remain visible.
